Algo Tili Lug'ati va Sintaksisi

Algo dasturlash tilining barcha kalit so'zlari, o'rnatilgan amallari va sintaksis qoidalari to'liq O'zbek tilidagi lug'atda jamlangan. Har bir amalni to'g'ridan-to'g'ri sinov maydonida sinab ko'rishingiz mumkin.

amal Kalit So'z

Funksiya va protseduralarni e'lon qilish uchun asosiy kalit so'z. Argumentlarni qabul qiladi va natija qaytaradi.

amal nom(arg1, arg2) { qaytar natija }
amal kvadrat(x) { qaytar x * x } amal asosiy() { chiqar("5 ning kvadrati:", kvadrat(5)) qaytar 0 }
asosiy Kirish Nuqtasi

Dasturning asosiy boshlang'ich nuqtasi (main function). Linux ELF binarining _start yorlig'idan chaqiriladi.

amal asosiy() { ... qaytar 0 }
amal asosiy() { chiqar("Algo dasturi boshlandi!") qaytar 0 }
agar / aks agar / aks Shart Operatorlari

Mantiqiy ifodaga ko'ra kod blokini shartli bajarish. 'if', 'else if' va 'else' muqobili.

agar shart { ... } aks agar shart2 { ... } aks { ... }
ball = 88 agar ball >= 90 { chiqar("A'lo") } aks agar ball >= 70 { chiqar("Yaxshi") } aks { chiqar("Qoniqarsiz") }
toki Sikl (While)

Belgilangan shart rost (1) bo'lib turguniga qadar blokni takroran bajaradi.

toki shart { ... }
i = 1 toki i <= 5 { chiqar("Sikl qadami:", i) i = i + 1 }
uchun / ichida Sikl (For .. In)

Sonlar oralig'i (a..b) yoki massiv elementlari bo'ylab iteratsiya qilish uchun ishlatiladi.

uchun i ichida 1..10 { ... }
yigindi = 0 uchun son ichida 1..5 { yigindi = yigindi + son } chiqar("Yig'indi:", yigindi)
tuzilma Tuzilma (Struct)

Bir nechta maydonlarni o'z ichiga oluvchi yangi ma'lumotlar turini e'lon qilish.

tuzilma Nom { maydon1, maydon2 }
tuzilma Muhandis { ism, unvon } nodir = Muhandis("Nodir", "Senior") chiqar(nodir.ism, nodir.unvon)
chiqar(...) O'rnatilgan Amal

Linux 'sys_write' tizim chaqiruvi orqali konsolga matn yoki qiymatlarni chop etadi.

chiqar(arg1, arg2, ...)
chiqar("Salom, Dunyo!") chiqar("Qiymatlar:", 10, 20.5, "Algo")
ildiz(x) Uskunaviy Amal

x86_64 protsessorining SSE2 SQRTSD ko'rsatmasi orqali tezkor apparatli kvadrat ildiz hisoblash.

ildiz(son) -> kasr haqiqiy son
chiqar("144 ning ildizi:", ildiz(144.0)) chiqar("2 ning ildizi:", ildiz(2.0))
tasodifiy(a, b) Kripto Amal

Linux yadrosi /dev/urandom yoki RDRAND ko'rsatmasidan xavfsiz tasodifiy butun son olish.

tasodifiy(min, max) -> butun son
tasodifiy_son = tasodifiy(100, 999) chiqar("Tasodifiy PIN:", tasodifiy_son)
Massivlar va Indekslar Ma'lumot Turi

Dinamik xotira massivlari. 0-dan boshlanuvchi indekslar, element o'qish va o'zgartirish.

[element1, element2, ...] | massiv[i]
sonlar = [10, 20, 30, 40] sonlar[1] = 99 chiqar("Uzunligi:", uzunlik(sonlar))
Lug'atlar (Hashmap) Ma'lumot Turi

Kalit-qiymat ko'rinishidagi assotsiativ massivlar (JSON obyektlari kabi).

{"kalit": qiymat, ...}
davlat = {"nom": "O'zbekiston", "poytaxt": "Toshkent"} chiqar("Poytaxt:", davlat["poytaxt"])
std/baza.algo Standart Modul

Diskda saqlanuvchi tranzaksiyali lokal Key-Value ma'lumotlar bazasi dvijogi.

yukla "std/baza.algo"
baza_och("ilovam.db") baza_yoz("foydalanuvchi", "Jasurbek") baza_saqla("ilovam.db")
Tizim Darajasidagi Arxitektura

Linux Yadrosi Bilan Bevosita Bog'lanish

Algo dasturlari oraliq virtual mashina (VM) yoki standart C kutubxonasiga tayanmaydi. Barcha operatsiyalar bevosita quyidagi Linux syscalllari orqali bajariladi:

Tizim Chaqiruvi (Syscall) Syscall Raqami Registrlar (Calling Convention) Vazifasi & Algo Amali
sys_write RAX = 1 RDI (fd), RSI (buf), RDX (len) Konsolga va tarmoq soketiga matn yozish: chiqar(), tarmoq_yubor()
sys_read RAX = 0 RDI (fd), RSI (buf), RDX (len) Fayl yoki soketdan ma'lumot qabul qilish: fayl_oqish(), kirit()
sys_socket RAX = 41 RDI (AF_INET=2), RSI (SOCK_STREAM=1) TCP tarmog'i server soketini ochish: server_yarat(port)
sys_bind / sys_listen RAX = 49 / 50 RDI (sock_fd), RSI (sockaddr), RDX (16) Portni tizimga bog'lash va ulanishlarni tinglash
sys_accept RAX = 43 RDI (sock_fd), RSI (0), RDX (0) Yangi kiruvchi HTTP mijozini qabul qilish: mijoz_kut()
sys_fork RAX = 57 Hech qanday argument talab qilmaydi Yangi parallel jarayon yaratish: jarayon_yarat()
sys_wait4 RAX = 61 RDI (pid), RSI (status), RDX (options) Yordamchi jarayon yakunlanishini kutish: jarayon_kut(pid)
sys_mmap RAX = 9 PROT_READ|PROT_WRITE, MAP_ANONYMOUS Dinamik xotira maydoni (Arena): xotira_holati(), xotira_tikla()

std/ Modullar Katalogi

Barcha modullar tilda o'rnatilgan holda keladi va yukla "std/..." orqali ulanadi.

std/http.algo
To'liq HTTP/1.1 backend freymvorki, status kodlari, JSON/HTML formatlovchi va marshrutlar.
http_metod http_yol http_javob_json http_javob_html http_tana
std/tarmoq.algo
To'g'ridan-to'g'ri TCP soket primitivalari. SO_REUSEADDR, tinglash va qabul qilish.
server_yarat mijoz_kut xabar_qabul xabar_yubor server_yop
std/baza.algo
Persistent Key-Value lokal ma'lumotlar bazasi. Tranzaktsion disk saqlash dvijogi.
baza_och baza_yoz baza_oqish baza_saqla baza_ochir
std/matematika.algo
SSE2 uskunaviy tezlashtirilgan ilmiy matematika, kvadrat ildiz, daraja, EKUB, trigonometriya.
ildiz daraja yaxlitla ekub ekuk sin cos
std/rang.algo
Terminal konsoli uchun 16 ta boy ANSI ranglar, fonlar, qalin va tagchiziqli formatlar.
rang_turkuaz rang_yashil rang_qizil rang_qalin rang_sariq
std/arxiv.algo
Run-Length Encoding (RLE) algoritmi orqali ma'lumotlarni tezkor siqish va qayta ochish.
arxiv_siqish_rle arxiv_ochish_rle
std/shablon.algo
Dinamik shablonlash dvijogi, HTML sanitizatsiya va lug'at parametrlarini o'rniga qo'yish.
shablon_almashtir shablon_lugatdan shablon_html_xavfsiz
std/csv.algo
CSV jadvallarni o'qish, tahlil qilish, ajratish va formatlash vositalari.
csv_qator_bol csv_qator_qur
std/bayroq.algo
CLI argumentlari va flaglarini (--port, --fayl, -v) avtomatik o'qish va tahlil qilish.
bayroq_matn_ol bayroq_butun_ol bayroq_bormi
std/sinov.algo
Birlik testlari freymvorki, taqqoslash tasdiqlari va formatlangan hisobotlar.
sinovchi_yarat sinov_teng_butun sinov_rost sinovchi_yakunla
std/yol.algo
Fayl tizimi yo'llarini birlashtirish, asosiy nom, papka va kengaytmani ajratish.
yol_birlashtir yol_asosiy yol_papka yol_kengaytma
std/navbat.algo
LIFO Stek (Stack) va FIFO Navbat (Queue) abstrakt ma'lumotlar tuzilmalari.
stek_yarat stek_qoy stek_ol navbat_yarat
